# Civic FA1 Dashboard v1.1.1 — unified clean-shell fix

Base: v0.9.5-CLEAN (full DashboardView + existing OBD stack).

## What changed
- Kept `DashboardView.java` as the active renderer; no Native Widgets replacement.
- Removed the legacy `refPatch` rectangle renderer from runtime code.
- Added one shared 1280×720 header geometry for CONNECT / SPORT / DIAGNOSTICS.
- Added one shared bottom-navigation geometry and one shared touch zone for all modes.
- CONNECT active = cyan, SPORT active = red, DIAGNOSTICS active = green.
- Removed runtime clock/Wi-Fi from the shared header; OBD state remains live.
- SPORT clean shell keeps the approved tachometer/body; runtime draws RPM arc, RPM, speed, sensor values, icons/titles/units/scales and fills.
- SPORT sensor picker remains enabled and saved selections still work.
- CONNECT and DIAGNOSTICS dynamic/example values are removed from the resource shell and redrawn live.
- Recent Devices selected row is outline-only (no filled dark rectangle).
- Version bumped to `1.1.1` / `versionCode 28` so it can install over v1.1.0.

## Intentionally unchanged
- `ObdManager.java`
- `ObdProtocol.java`
- `SensorFreshness.java`
- `MainActivity.java` lifecycle/OBD behavior
- BLE / BT / Wi-Fi transport logic
- OBD polling scheduler and dynamic RPM arc policy
